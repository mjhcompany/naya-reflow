# naya-reflow knowledge bundle

Open Knowledge Format (OKF) bundle describing the **naya-reflow** project: reverse-engineered hardware, USB CDC protocol, firmware and tooling for the (bankrupt) Naya Create split keyboard. Archived snapshot as of Sep–Oct 2026; development moved to create-reflow. See [Project status](/overview/project-status.md) before trusting any claim.

* [Overview](overview/) - what the product and the project are, and how reliable this knowledge is
* [Hardware](hardware/) - halves, modules, dongle, power architecture
* [Protocol](protocol/) - USB CDC framing, command map, keymap/LED formats, bootloader, BLE
* [Firmware](firmware/) - signing-key situation and the stock image archive
* [Playbooks](playbooks/) - runnable recovery and remap procedures
* [Tools](tools/) - the Python/C toolkit
* [Software](software/) - the WebSerial web client
